# 营地噪声投诉处置系统

为露营地配置营位安静时段与相邻关系，受理噪声投诉（可对被投诉方匿名），
记录值班员到场时间、分贝读数照片与沟通结果，并完成申诉、主管复核结案、
换位建议与统计。**纯 Python 标准库实现，零第三方依赖**（SQLite + http.server）。

## 一条命令启动

```bash
./run.sh            # 默认 8000 端口；./run.sh 8123 指定端口
```

启动时会：重置数据库 → 生成重复投诉样例（同一起 A-02 深夜音响事件的
3 次投诉合并、篝火晚会豁免、设备误报、历史结案事件）→ 启动 Web 台。

打开 <http://127.0.0.1:8000>：

| 页面 | 内容 |
|---|---|
| `/map` 营位图 | 编号 + 相邻边线（距离米）+ 安静时段 🌙 + 活跃事件；`?incident=N` 高亮影响范围 |
| `/incidents` 事件受理 | 事件列表、提交投诉、撤回投诉 |
| `/incidents/1` 投诉详情 | **发生 → 到场 → 复核** 时间线、投诉链、分贝照片、处置/申诉/复核、消息留痕 |
| `/relocate` 换位建议 | 持续超限自动生成的换位方案，接受即完成换营位（历史入住保留） |
| `/review` 复核统计 | 复核队列、状态/处置/申诉统计、到场时长、人员接单量 |

详情页右上角可切换 **被投诉方视图（匿名隔离自检）**，直观核对投诉人身份被隐去。

## 业务规则

- **投诉链合并**：同一被投诉营位、事件仍活跃、首诉在 90 分钟窗口内的后续投诉
  并入同一事件（`is_duplicate=1`），`merged_count` 累加；豁免事件不参与合并。
- **匿名隔离**：投诉人姓名/营位/联系方式仅内部视图可见；被投诉方视图一律
  显示“匿名住客 / 邻近营位”；发给被投诉营位的消息 `redacted=1`，正文不含投诉人。
  实名投诉显示姓名，但仍不暴露联系方式。撤回需本人 `anon_token`。
- **安静时段**：22:00–07:00 跨午夜，**左闭右开**（22:00:00 入夜间，07:00:00
  已离开）；夜间限值 45 dB、白天 55 dB，按读数发生时刻适用。
- **公共活动豁免**：已报备活动（global 或指定营位）时段的投诉受理但免予处置，
  事件直接驳回并留痕；到场时若进入豁免期，只能登记 exempt。
- **持续超限 / 误报**：设备故障读数为 NULL 且照片标注 FAULT，不能作为超限依据；
  两次及以上有效读数超限才算“持续”，升级至 3 级自动生成换位建议
  （目标营位与问题营位不相邻、无人住、无活跃事件）。
- **撤回**：事件内投诉全部撤回且尚无现场处置时事件撤销；已到场处置的事件保留。
- **申诉与复核**：巡查员不能关闭自己提交、尤其被申诉的处置记录（服务层拒绝 +
  SQLite 触发器 `trg_appeal_review_required` 兜底）；必须由值班主管
  （不得是记录人本人）复核后才可结案/撤销/退回跟进。
- **接单竞争**：单条条件 `UPDATE ... WHERE assigned_officer_id IS NULL AND
  status='open'` 抢占，SQLite 行锁保证并发下只有一名现场负责人。
- **换营位**：旧入住 `check_out` 关闭、新开一条 occupancy，历史快照可追溯。

## 模拟接口

- `app/meter.py` `MockSoundMeter`：返回读数，`fault=True` 模拟设备故障；
  同时手写 PNG 快照存到本地 `data/readings/`（深灰底/警示橙配色）。
- `app/messaging.py` `MessageService`：所有“发送”落 `messages` 表留痕，
  含 `redacted` 脱敏标记，不外联。

## 测试

```bash
python3 -m unittest discover -s tests -v
```

30 个用例覆盖：**匿名隔离**（被投诉方视图无姓名/营位/联系方式、消息脱敏、
实名边界、撤回凭证）、**事件合并**（窗口内外、不同营位、已结案不再吸收）、
**时段边界**（22:00 含、07:00 不含、跨午夜、限值切换）、**接单竞争**
（3 线程屏障并发，恰一名负责人），以及豁免、撤回、误报、持续升级、
主管复核与换位历史。

## 目录

```
app/db.py         SQLite 表结构与触发器（投诉链/复核约束）
app/timeutil.py   安静时段、限值、豁免判定
app/meter.py      模拟分贝计 + PNG 快照
app/messaging.py  模拟消息服务（留痕/脱敏）
app/services.py   全部业务规则与脱敏视图/时间线/统计
app/seed.py       重置并生成重复投诉样例
app/web.py        HTTP 界面（每请求独立连接，线程安全）
static/style.css  夜间深灰 / 浅色正文 / 警示橙
tests/            匿名隔离、合并、时段边界、接单竞争等
run.sh            一条命令启动
data/             运行时生成：camp.db、readings/*.png（git 忽略）
```
