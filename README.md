# 营地噪声投诉处置系统

面向露营地值班场景的噪声投诉受理与处置闭环。纯 Python 标准库实现（**零第三方依赖**），
SQLite 保存投诉链，音量读数照片存本地 PNG，分贝计与消息服务均为可替换的模拟接口。

## 一条命令启动

```bash
./run.sh          # 默认 http://127.0.0.1:8000
./run.sh 9000     # 指定端口
```

启动时自动建库、写入一套**重复投诉合并**演示样例（含匿名、持续超限+申诉、设备误报、
投诉撤回、公共活动豁免、待接单新投诉），随后启动本地 Web 服务。
首次打开建议：营位图 → 事件受理 → 点开事件 →（右上角切换到值班主管）→ 复核。

> 想从空库开始：`python3 -m app.main --no-seed`；重置演示数据：加 `--reset`。

## 功能与页面

| 页面 | 内容 |
|---|---|
| 营位图 `/` | 8 个营位用**编号**与**相邻关系线**表达；选中营位后橙色高亮其直接相邻边（影响范围），列出邻居、入住住客与换位备选 |
| 事件受理 `/events` | 提交投诉（可勾选匿名）、查看事件列表与每条事件的投诉合并数/到场数/状态 |
| 事件详情 `/events/<id>` | **投诉详情按 发生 → 派单 → 到场 → 申诉 → 复核 排序的时间线**；投诉链、现场记录与读数照片、接单/记录/申诉/复核操作、换位建议 |
| 复核 `/review` | 被申诉处置队列；仅值班主管可给出“维持/改判误报/发回重查”并结案 |
| 统计 `/stats` | 事件总量、合并投诉、匿名、持续超限升级、设备误报、撤回、豁免等指标与状态分布、模拟消息发送记录 |

右上角可切换 **巡查员 / 值班主管 / 住客** 三种视角（Cookie 保存）。

## 业务规则

- **安静时段**：每营位 `22:00–07:00`（可配，允许跨午夜），采用半开区间 `[22:00, 07:00)`：
  `22:00:00` 即夜间，`07:00:00` 解除。限值日间 55 dB、夜间 45 dB。
- **事件合并**：同一被投诉营位、30 分钟窗口内、未结案事件的多次投诉自动合并为一条投诉链；
  不同营位不合并；已撤回/误报关闭的事件不参与合并。
- **匿名隔离**：匿名投诉在面向被投诉方的视图中只显示“匿名投诉人 N”，隐藏姓名、电话与营位；
  数据库内部仍保留可追溯投诉链。模拟消息服务发送的任何通知都不含投诉人身份。
- **投诉撤回**：撤回单条投诉；若该事件再无有效投诉，事件关闭为“已撤回”。
- **现场记录**：只有接单负责人可提交；记录到场时间、读数时间、分贝读数、沟通结果并生成读数照片。
  - **持续超限**：夜间两次“有效且超限”读数间隔 ≤15 分钟 → 自动升级处置；
  - **设备误报**：分贝计自检失败时读数不采信、不生成照片，事件按误报登记；
  - 单次超限保持处置中继续观察，未超限则口头提醒后归档。
- **公共活动豁免**：登记的全营地/单营位活动时段内，投诉仍受理留痕，但直接以豁免归档、不派单。
- **住客换营位**：换位建议按营位图 BFS 跳数推荐距离最远的空营位，排除相邻与已占用营位。
- **申诉与复核**：处置（含误报判定）可被申诉；**巡查员不能关闭被申诉记录，值班主管复核后才可结案**。
- **并发接单**：`BEGIN IMMEDIATE` 写事务 + 条件 `UPDATE ... WHERE status='open'`，
  保证并发接单只有一名现场负责人，接单日志也只落一条。详情页提供“模拟两人同时并发接单”按钮。

## 模拟接口（`app/devices.py`）

- `DecibelMeter.read()`：返回带确定性抖动的读数；`force_fault=True` 或周期触发时返回
  `device_ok=False` 的设备误报。
- `MessageService.send()/notify_officer()/notify_review_needed()`：写入 `messages_log` 表，
  页面“统计”可见，绝不携带投诉人身份。
- `save_reading_photo()`：仅用 `zlib/struct` 现场渲染 320×180 的分贝计显示屏 PNG（深灰底、
  浅色读数、超限时警示橙、含限值刻度与量条），保存到 `data/photos/`。

## 目录结构

```
app/
  database.py   SQLite schema、连接/事务、相邻关系
  rules.py      安静时段、合并、豁免、阈值与持续超限、换位 BFS
  devices.py    模拟分贝计、消息服务、读数照片 PNG 渲染
  services.py   受理/撤回/接单竞争/现场记录/申诉复核/换位/统计
  seed.py       营地拓扑与演示样例
  views.py      服务端渲染页面（夜间主题）
  templates.py  布局/配色/状态徽标
  server.py     标准库 HTTP 路由
  main.py       命令行入口
tests/
  test_core.py  规则与服务单元/并发测试
  test_http.py  真实线程服务器端到端测试
run.sh          一条命令：重置+种子+启动
```

## 运行测试

```bash
python3 -m unittest discover -s tests -v
```

覆盖：匿名身份隔离（页面与消息均不泄露）、事件合并（窗口内/跨窗口/跨营位）、
安静时段边界（21:59:59 / 22:00:00 / 06:59:59 / 07:00:00）、
2 人与 8 线程接单竞争、持续超限升级、设备误报、撤回、豁免边界、换位、
巡查员越权复核被拒与主管结案，以及 HTTP 端到端闭环。

## 主题

夜间深灰底（`#17181a`）、浅色正文（`#e7e7e0`），警示橙（`#e87e29`）仅用于
待处理/超限/告警；蓝=进行中、绿=已达标、黄=待复核，状态均带图标与文字，不依赖颜色单独表意。
